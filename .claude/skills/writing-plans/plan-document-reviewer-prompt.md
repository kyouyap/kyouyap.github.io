# 計画ドキュメントレビュアー プロンプトテンプレート

計画ドキュメントレビュアーサブエージェントをディスパッチする際にこのテンプレートを使用する。

**目的:** 計画が完全であり、仕様に一致し、適切なタスク分解がされているかを検証する。

**ディスパッチタイミング:** 計画の完成後。

```
Task tool (general-purpose):
  description: "Review plan document"
  prompt: |
    あなたは計画ドキュメントのレビュアーです。この計画が完全で実装準備が整っているかを検証してください。

    **レビュー対象の計画:** [PLAN_FILE_PATH]
    **参照用の仕様:** [SPEC_FILE_PATH]

    ## 確認事項

    | カテゴリ | 確認ポイント |
    |----------|-------------|
    | 完全性 | TODO、プレースホルダー、未完了タスク、欠落ステップ |
    | 仕様との整合性 | 計画が仕様の要件をカバーしている、大幅なスコープクリープがない |
    | タスク分解 | タスクに明確な境界がある、ステップが実行可能 |
    | 構築可能性 | エンジニアがこの計画に従って行き詰まらずに実装できるか？ |

    ## 判断基準

    **実装中に実際の問題を引き起こすものだけを指摘すること。**
    実装者が間違ったものを構築したり行き詰まったりすることは問題である。
    細かい表現、スタイルの好み、「あると良い」程度の提案は問題ではない。

    深刻なギャップがない限り承認する -- 仕様からの要件の欠落、
    矛盾するステップ、プレースホルダーの内容、曖昧すぎて実行できないタスク。

    ## 出力形式

    ## Plan Review

    **Status:** Approved | Issues Found

    **Issues (if any):**
    - [Task X, Step Y]: [具体的な問題] - [実装にとってなぜ重要か]

    **Recommendations (advisory, do not block approval):**
    - [改善の提案]
```

**レビュアーの返却内容:** Status、Issues（あれば）、Recommendations
