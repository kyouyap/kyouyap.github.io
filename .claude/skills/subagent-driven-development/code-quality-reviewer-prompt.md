# コード品質レビュアー プロンプトテンプレート

コード品質レビュアーサブエージェントをディスパッチする際にこのテンプレートを使用する。

**目的:** 実装が適切に構築されているか（クリーン、テスト済み、保守性が高い）を検証する

**仕様準拠レビューに合格した後にのみディスパッチすること。**

```
Task tool (code-reviewer):
  Use template at requesting-code-review/code-reviewer.md

  WHAT_WAS_IMPLEMENTED: [実装者のレポートより]
  PLAN_OR_REQUIREMENTS: Task N from [plan-file]
  BASE_SHA: [タスク開始前のコミット]
  HEAD_SHA: [現在のコミット]
  DESCRIPTION: [タスクの概要]
```

**標準的なコード品質の観点に加え、レビュアーは以下を確認すべき:**

- 各ファイルが明確な責務を1つ持ち、well-defined なインターフェースを備えているか？
- ユニットが独立して理解・テストできるように分解されているか？
- 計画のファイル構成に従った実装になっているか？
- この実装で新規作成されたファイルが既に大きくなっていないか、または既存ファイルを大幅に肥大化させていないか？（既存のファイルサイズは指摘不要 -- この変更が増やした分に注目すること。）

**コードレビュアーの返却内容:** 長所、問題点（Critical/Important/Minor）、評価
