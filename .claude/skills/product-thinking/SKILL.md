# プロダクト思考

## 概要

ユーザーの目的を最短で達成し、シュッと出番を終えるプロダクトを作るための思考原則。

**中核原則:** アプリはユーザーの目的達成の脇役。最短で価値を届け、負荷なく使えることが最優先。

## 10の原則

### 1. 脇役に徹する

アプリは業務やコミュニケーションの主役ではない。欲しいものを最短で提供し、出番を終える。

**判断基準:** この機能はユーザーの目的達成を早めるか、それともアプリ自身の存在感を主張しているだけか？

### 2. 楽なUI > すごそうなUI

新しさや先進性の演出より、直感的で戻りやすく取り消しやすい形を選ぶ。

**判断基準:** ユーザーが迷わず操作でき、間違えてもすぐ戻れるか？

### 3. スクロールは安全な操作

スクロールはボタンやリンクより心理的ハードルが低い。戻りやすく、段階的に情報を拾え、現代のユーザーは慣れている。

**判断基準:** ボタンやページ遷移で分割するより、スクロールで段階的に見せる方が自然ではないか？

### 4. 機能追加 = 複雑さ増加

機能や設定の追加はコードだけでなくユーザーの認知負荷も高める。特に新規・ライトユーザーへの影響が大きい。

**判断基準:** ファーストビューにボタンが1個増えることを許容できるか？しばらく寝かせて考えたか？

### 5. デフォルトがベスト

ほとんどのユーザーは設定をいじらない。デフォルトのままが最も快適な体験になるよう設計する。好みが分かれる重要項目はオンボーディングで選択してもらう。

**判断基準:** デフォルト設定のまま使うユーザーが最も快適か？設定を探しに行かないと不快な体験になっていないか？

### 6. 操作をブロックしない

処理中も他の操作ができ、中断したいときにすぐ中断でき、雑に操作してもやりたいことができる形を目指す。

**判断基準:** ユーザーは待ち時間中に何もできない状態になっていないか？

### 7. 説明文に頼らない

アプリ内の説明文はほぼ読まれない。スマホで4行を超える説明は、読まれないうえ「ややこしい」印象を与える。

**判断基準:** 長文なしで使い方が伝わるか？必要なら強弱をつけて段階的に見せられるか？

### 8. 汎用性より快適さ

ターゲットユーザーの主要ユースケースに最適化し、その体験を突き詰める。全ユースケースを平等にカバーしようとしない。

**判断基準:** 80%のユーザーの体験を最高にすることと、100%をカバーすることのどちらを優先しているか？

### 9. 速度にこだわる

外部APIの待ち時間以外は10msでも速く。機能追加時は既存機能の速度に影響がないかチェックする。

**判断基準:** この変更は既存機能のレスポンスを遅くしていないか？

### 10. 主観で作る

「自分ならどう感じるか」を最大の指針にする。同じ感覚を持つユーザーに刺さるものを作ると割り切る。

**判断基準:** 自分が毎日使いたいと思えるか？

## 設計判断チェックリスト

| 判断場面 | 確認すること |
|----------|-------------|
| 機能追加 | 認知負荷は増えないか？デフォルトで最適か？ |
| UI設計 | スクロールで解決できないか？説明文なしで伝わるか？ |
| 設定追加 | デフォルト値は大多数にとってベストか？ |
| 処理中の画面 | ユーザーの操作をブロックしていないか？ |
| パフォーマンス | 既存機能の速度に影響していないか？ |
| スコープ | 主要ユースケースの体験を犠牲にしていないか？ |

## よくあるミス

| ミス | 原則 |
|------|------|
| 見栄えの良い複雑なレイアウトを優先 | #2 楽なUI > すごそうなUI |
| モーダルやステップウィザードで画面を分割 | #3 スクロールは安全 |
| 「あったら便利」で機能追加 | #4 機能追加 = 複雑さ |
| 設定項目で柔軟性を担保しようとする | #5 デフォルトがベスト |
| ローディング中に全操作を無効化 | #6 ブロックしない |
| 使い方の長文説明を画面に配置 | #7 説明文に頼らない |
| 全ユーザーを等しく満足させようとする | #8 汎用性より快適さ |

## brainstorming との連携

brainstorming の「アプローチを探る」フェーズで UI/UX の設計判断が必要になったとき、本スキルの10原則と設計判断チェックリストを適用する。

特に以下の場面で参照:
- 新しい画面・コンポーネントの設計方針を決めるとき
- 機能追加のスコープを判断するとき
- 複数のUI案からトレードオフで選択するとき
